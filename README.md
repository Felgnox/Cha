# Cha Audio Visualizer — v0.1\n\nFirst interactive prototype of Cha Studio.\n\n## Included\n- Live canvas visualization (Spectrum, Mirror, Wave, Particles)\n- Audio file upload and playback through Web Audio analyser\n- Color, density, amplitude and vertical placement controls\n- Editable track title and artist\n- Aspect ratio controls\n- Basic WebM capture export (canvas video + audio stream)\n\n## Run locally\n\`\`\`bash\nnpm install\nnpm run dev\n\`\`\`\n\nThis is an initial UI prototype; next iterations can improve audio timeline, export codecs/resolution, effects, and project saving.\n
